#  Flashcard Study App

A desktop flashcard application built with **Python**, **Tkinter**, and **SQLite**. 
Create your own decks of flashcards, edit them, and test your knowledge with the built-in quiz mode.

##  Features

- **Add Cards:** Create new flashcards with a category, question, and answer.
- **Edit / Update:** Click any card in the list to load its data, modify it, and save the changes.
- **Delete Cards:** Remove unwanted cards from the database.
- **Study Mode:** Load a shuffled deck, type your answers, and get instant feedback.
- **Score Tracking:** Keeps track of your correct and wrong answers during each study session.
- **Persistent Storage:** All your cards are saved permanently to a local `flashcards.db` SQLite database.

##  Technologies Used

- **Python 3.x** (Standard Library only)
- **Tkinter** (GUI Framework)
- **SQLite3** (Database)
- **Random** (Shuffling the quiz deck)
